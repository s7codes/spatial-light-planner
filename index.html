    Keyboard Shortcuts

    Press ? at any time to toggle this guide.

    Shortcut Action
    Drag item Move item on wall (with 1 cm magnetic alignment)
    Hold Alt / Option while dragging Temporarily bypass magnetic alignment guides
    Arrow Keys Nudge selected item by 1 cm
    Ctrl + Z / Cmd + Z Undo last layout action (up to 30 steps)
    Ctrl + Y / Ctrl + Shift + Z Redo layout action (Cmd + Shift + Z on Mac)
    Ctrl + D / Cmd + D Duplicate selected item (+4 cm offset)
    L Lock or unlock selected item position and properties
    Delete / Backspace Remove selected unlocked item
    ? Toggle Keyboard Shortcuts guide
    Escape Close open modal or deselect active item

    Shift + click adds or removes an item, dragging across empty wall draws a selection box, and Ctrl + A selects everything. With several items selected, moves, nudges, locks, duplicates and removals apply to the whole group. Right-click an item for its menu.

    R turns the selection 90 degrees clockwise. Hold Alt / Option with something selected and point at another item, or at bare wall, to measure the distance to it.

    Ctrl + G groups the selection and Ctrl + Shift + G ungroups it. Double-click a grouped item to pick it on its own, or a text note to edit it.

    Drag from the top or left ruler to pull out a reference guide, and drag it off the wall or double-click it to remove it.

    Ctrl + C, Ctrl + X and Ctrl + V copy, cut and paste the selection, each paste landing 4 cm further along.

    Ctrl + Wheel zooms around the pointer and Ctrl + 0 resets zoom and pan. Hold Space and drag, or drag with the middle button, to pan the view.

    Ctrl + K / Cmd + K opens the command palette: type to filter, walk the list with the arrow keys and press Enter to run a command.

    Alt + M / Option + M switches between Engineer Mode, with rulers, guides, layers and exact coordinates, and the decluttered Creator Mode for arranging and lighting.
