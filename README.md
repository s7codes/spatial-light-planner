# Spatial & Ambient Light Planner 🛋️💡

An interactive 2D room wall layout and smart ambient lighting simulator built for planning shelving, wall art, and RGB lighting setups to scale.

## Key Features & Development Progress
* **v0.1:** 3-column studio workspace architecture, scaled 2D coordinate canvas (`1 cm = 2.5 px`), and hardware-accelerated CSS ambient LED light simulation.
* **v0.2:** Interactive Daylight Blueprint vs. Night Ambient mode toggle (`10×10 cm` scale grid), real-time RGB color pickers, master brightness dimmer (`0–100%`), and instant scene presets.
* **v0.3 (Current):** Dynamic component catalog spawning (click-to-mount shelves, cubes, posters, spotlights, corner lamps), real-time budget calculation via `Array.reduce()`, and interactive item inspector with deletion handler.
* **v0.4 (Upcoming):** Drag-and-drop spatial movement and boundary collision detection.
