# Spatial & Ambient Light Planner 🛋️💡

An interactive 2D room wall layout and smart ambient lighting simulator built for planning shelving, wall art, and RGB lighting setups to scale.

## Key Features & Development Progress
* **v0.1:** 3-column studio workspace architecture, scaled 2D coordinate canvas (`1 cm = 2.5 px`), and hardware-accelerated CSS ambient LED light simulation.
* **v0.2 (Current):** Interactive Daylight Blueprint vs. Night Ambient mode toggle (`10×10 cm` scale grid), real-time RGB color pickers, master brightness dimmer (`0–100%`), and instant scene presets via CSS Custom Properties.
* **v0.3 (Upcoming):** Interactive catalog item spawning, drag-and-drop spatial placement with wall boundary collision detection, and live budget calculation.
