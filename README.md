# Spatial & Ambient Light Planner 🛋️💡

An interactive 2D room wall layout and smart ambient lighting simulator built for planning shelving, wall art, and RGB lighting setups to scale.

## Key Features (Roadmap)
* **v0.1 (Current):** 3-column studio workspace architecture, scaled 2D coordinate canvas (`1 cm = 2.5 px`), and hardware-accelerated CSS ambient LED light simulation.
* **v0.2 (Upcoming):** Interactive Day/Night (Ambient) mode toggle and dynamic RGB color temperature controls.
* **v0.3:** Drag-and-drop spatial placement with boundary collision detection and live budget calculation.
